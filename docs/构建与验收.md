# 构建与验收

## 构建环境

- Apple 芯片 Mac。运行目标最低 macOS 14。
- Xcode 和 Swift 6 或更新工具链。iOS/iPadOS 部署目标为 17.0。
- 构建时需要拉取固定版本的 OSS Swift SDK 0.4.0 和 AWS SDK for Swift 1.8.35。

## Mac

```bash
swift test --arch arm64
./scripts/build-macos.sh
open dist/alioss4ios.app
```

脚本构建 arm64、装配资源并完成本地临时签名。交付目录是本地生成目录，包未做 Developer ID 签名和公证。

## iPhone 与 iPad

用 Xcode 打开 `alioss4ios.xcodeproj`，选择模拟器或已连接的真机。模拟器构建保留 Xcode 签名，使应用可访问自身钥匙串。真机使用开发团队签名。

```bash
xcodebuild -project alioss4ios.xcodeproj -scheme alioss4ios \
  -configuration Debug -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath DerivedData build
```

构建产物位于 `DerivedData/Build/Products/Debug-iphonesimulator/alioss4ios.app`。如需从命令行安装到已启动的模拟器，运行 `xcrun simctl install booted DerivedData/Build/Products/Debug-iphonesimulator/alioss4ios.app`。多个模拟器同时启动时将 `booted` 换成目标设备 UDID。
