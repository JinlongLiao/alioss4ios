# 贡献指南

## Git 与本地文件

仓库地址为 [JinlongLiao/alioss4ios](https://github.com/JinlongLiao/alioss4ios)，SSH 远程为 `git@github.com:JinlongLiao/alioss4ios.git`。本地默认分支为 `main`。

源码、测试、Xcode 工程文件、脚本和文档可纳入版本控制。应用包、Xcode 用户状态、编译缓存、钥匙串导出、配置备份和签名材料属于本地文件。依赖锁文件生成后可随应用源码核对和维护。提交前核查 AccessKey、SessionToken 和真实端点配置。

## 格式与验证

- Swift 使用四空格缩进，文本统一 UTF-8 和 LF，遵循 `.editorconfig` 与 `.gitattributes`。
- 改动存储和行为时运行 `swift test --arch arm64`。界面改动核对 Apple 芯片 Mac、iPhone 和 iPad 的相应布局。
- 对照 Android 时记录验证实际覆盖的设备、操作和边界。依赖替身验证与真实 Bucket 联调分别记录。
- 提交信息参考 Android 工程的 Conventional Commits。提交保持单一主题，PR 附验证结果，界面变更可附截图。

```bash
git remote -v
git status --short
git diff --check
swift test --arch arm64
```
