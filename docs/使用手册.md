# 使用手册

## 安装与启动

- Apple 芯片 Mac 使用 macOS 14 或更新版本，构建后打开 `dist/alioss4ios.app`。
- iPhone 和 iPad 使用 iOS/iPadOS 17 或更新版本。用 Xcode 打开 `alioss4ios.xcodeproj`，选择 `alioss4ios` scheme。真机安装需要开发团队签名。构建详见 [构建与验收](构建与验收.md)。

首次启动会展示隐私说明。「设置」可新增账号或导入 ALOS 配置备份。文件页左上角可切换已保存账号；宽屏左栏同时保留 Bucket 列表。

## 配置存储

在「设置 → 账号」添加连接。选择 OSS 或 S3，填写名称、区域、AccessKey ID 和 Secret。临时凭据还要填写 SessionToken。可使用与 Android 同源的 OSS 公网地域或 S3 区域预置，也可手动输入。选择 OSS 预置时会填充空白或标准公网端点，并保留自定义 HTTPS 端点及其部署路径。S3 兼容网关可按服务端要求开启 path-style。

账号权限只覆盖单个 Bucket 时，填写默认 Bucket 避免依赖账号级 Bucket 枚举权限。确认凭据、区域和权限后，保存并激活账号。

## 浏览与操作

- 「文件」进入 Bucket 与目录。紧凑宽度下在桶列表和内容之间切换，宽屏保留侧栏。
- 直接在文件页路径栏输入目录或对象 key，按回车或「前往」提交。命中对象时进入父目录并高亮。文件页可直接切换列表和网格，排序在更多菜单。Bucket 行显示服务已返回的地域、存储类型及创建日期。长按 Bucket 可复制已知 Endpoint。
- 名称正序按需分页，可继续浏览超过 10000 项的目录。名称倒序和两种修改时间排序需要完整扫描当前目录。超出 10000 项时，请切换为名称正序或进入子目录。
- 打开 XML、JSON、YAML、TXT 或 Markdown 等文本后，点击「编辑」和「查看差异」。核对完整 Bucket 路径和带 + / - 的逐行对比，再点「确认更新」写回原对象。成功后回到同一文件的预览并显示新正文，下一次编辑使用本次写入返回的 ETag。写入未返回新 ETag 时仍可查看已保存正文，重新打开文件后再编辑。失败时保留草稿。
- 支持无损保留 UTF-8、UTF-16 及可识别的 XML 声明编码。正文未返回 ETag 时会查询对象元数据，也可使用列表中的版本发起条件重读。只有服务端接受该条件时才开放编辑。版本或编码无法验证时，仍可预览。写回 S3 会由服务端校验打开预览时的 ETag。OSS 写入前复查 ETag，复查与写入之间存在并发窗口。修改后的文本继续受预览大小限制，保存确认页会提示对象级访问权限可能变化。
- 文件可预览、下载、生成链接、移动或重命名。目录支持新建、删除及同 Bucket 递归移动。
- 「设置 → 安全」开启二次确认后，删除需要确认，移动或重命名先填写目标，再核对源路径和目标路径。
- 上传入口允许选择多个文件。「上传任务」显示队列、暂停、继续、撤销及历史清理。大文件从已确认分片恢复，继续前检查原账号、路由和源文件属性。

Mac 关闭窗口后上传可继续运行。iPhone 和 iPad 将已准备的大文件分片和 OSS/S3 小文件交给系统后台会话。准备下一片和合并对象仍依赖应用获得执行时间。OSS 上传需有 `oss:GetBucketVersioning` 权限，应用会在写入前验证 Bucket 是否支持防覆盖条件。系统终止应用后，若后台会话交付成功回执，应用会保存该分片。重新打开可从最近保存的断点继续。挂起期间的传输尚待真机验收。

## 外观

「设置 → 配色主题」展示与 Android 同顺序和名称的 18 套主题，可先看浅色缩略预览。更换配色会同时更新文件页和设置页。明暗模式可独立选择。

## 预览、分享和备份

文本和 Markdown 使用应用内预览，音视频由系统播放器打开。图片、PDF 及部分文档使用 Quick Look，格式与编码支持随系统变化。

HTML 和图片由当前账号直接读取。HTML 顶栏的「源码」可滚动并选择复制原文，「预览」返回页面。静态预览默认禁用脚本和外部请求。「开启完整网页预览」经确认后仅本次允许 JavaScript 和 HTTPS 外部资源。若显示 HTTP 403，请检查账号是否具备该对象的读取权限，并保留失败请求 ID 供排查。

签名链接可选择 1～168 小时有效期，也可复制或通过系统分享。公开链接的访问权限由对象及 Bucket 配置决定。

在「设置 → 备份与恢复」导入或导出 Android 兼容的 ALOS v1 配置备份，导出后缀为 `.aloss`，旧 `.alos` 文件仍可导入。备份选择器只选择这两种文件类型。填写密码会使用密码加密，留空并确认后使用共用应用密钥。免密码备份应按账号配置文件保管，获取文件的人可以读取其中凭据。
